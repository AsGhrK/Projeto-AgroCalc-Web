Glossário

Termos essenciais

Bit

Menor unidade de informação digital, podendo valer 0 ou 1. Abreviatura de "binary digit".

Byte

Conjunto de 8 bits usado para representar caracteres e pequenos valores.

Processamento

Etapa em que a CPU executa instruções e transforma dados em resultado útil.

CPU

Unidade central de processamento responsável por executar instruções do programa.

RAM

Memória de acesso aleatório, usada para dados temporários durante a execução.

Determinante

Valor calculado de uma matriz que indica se o sistema linear tem solução única.

Matemática — Conjuntos

Classificação de insumos agrícolas

Aplicação da teoria dos conjuntos na organização de insumos por categoria. Cada insumo pertence a um conjunto definido por critério de origem e composição.

Orgânicos (O)

  • Esterco bovino
  • Composto vegetal
  • Biofertilizante líquido
  • Farinha de ossos

Químicos (Q)

  • Ureia (45% N)
  • Superfosfato simples
  • Cloreto de potássio (KCl)
  • MAP (monoamônio fosfato)

Híbridos — O ∩ Q (H)

  • Fertilizante organomineral granulado
  • Composto enriquecido com NPK
  • Bioestimulantes com micronutrientes
Conjunto Critério de pertinência Relação
Orgânicos (O)Origem biológica, sem síntese químicaO ∩ Q = ∅ (puros)
Químicos (Q)Sintetizados industrialmenteQ ∩ O = ∅ (puros)
Híbridos (H)Combinação de orgânico + mineralH ⊂ O ∪ Q
